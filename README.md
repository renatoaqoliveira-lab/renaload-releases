# Renaload — instaladores

Este repositório guarda **apenas os instaladores** do Renaload e as notas de
cada versão. O código-fonte do aplicativo é privado e não fica aqui.

## Baixar

- **Página de download:** https://renatoaqoliveira-lab.github.io/renaload-releases/
- **Última versão, direto:**
  https://github.com/renatoaqoliveira-lab/renaload-releases/releases/latest

O Renaload também se atualiza sozinho: ao abrir, ele verifica se há uma versão
mais nova e oferece a atualização, conferindo o SHA-256 do arquivo antes de
executar qualquer coisa.

## Licença de uso

O Renaload é um software licenciado. O instalador é público para permitir a
primeira instalação e as atualizações, mas o uso contínuo exige um token de
ativação válido. Para adquirir, entre em contato com o suporte.

Use o Renaload somente com conteúdos próprios, autorizados, livres de direitos,
em domínio público ou quando a plataforma e o titular dos direitos permitirem.
