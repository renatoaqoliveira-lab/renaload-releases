Uso responsavel

O Renaload deve ser usado apenas com conteudos proprios, autorizados, livres de direitos, em dominio publico ou quando o download for permitido pela plataforma e pelo titular dos direitos. O usuario e responsavel pelo uso.

Como funciona

Cole, escolha, baixe.

O Renaload detecta links copiados, valida a origem e oferece controles para formato, qualidade, cookies, metadados e compatibilidade com editores.

  1. 1Cole o link

    Use links de conteudos que voce tem direito de acessar e baixar.

  2. 2Escolha o formato

    Audio, video, qualidade, pasta e ajustes de compatibilidade.

  3. 3Baixe com controle

    Acompanhe a fila e receba avisos quando alguma plataforma precisar de login.

Licenciamento

Ativacao por token, sem servidor proprio.

Cada cliente recebe um token assinado. O app valida a licenca no proprio computador e consulta uma lista assinada no GitHub para cancelamentos.
